## NetShutUp 0.1.0-alpha.1 (pre-release)

The first test build. **This is for testers.** The part that changes settings is covered by tests but has not yet been proven on many real computers, so please read the safety notes and use the self-test.

### What it does

Pick a profile (**Privacy**, **Performance** or **Recommended**), see exactly what would change, confirm, and the program backs up first, applies, and checks the result. One command undoes it.

- Interactive arrow-key menu (double-click the `.exe`) or plain commands: `scan`, `preview`, `apply`, `revert`, `selftest`.
- Encrypted DNS: points your adapters at Quad9, Cloudflare or Google with DNS-over-HTTPS required, proves it with real lookups, tries the next provider, and restores your old DNS if nothing works. **DNS-over-TLS is tried after DoH and is experimental.** Needs Windows 11.
- Windows Firewall base tier: makes sure the firewall is on and blocks inbound by default (skipped if another firewall is registered). On most computers this changes nothing.
- **Self-test mode:** applies each profile for real, undoes it, checks the computer is back as it was, and writes a masked `.md` + `.json` report. Before it changes anything it exports the relevant registry keys and creates a System Restore point.

### Try it (testers)

1. Download `NetShutUp-v0.1.0-alpha.1-windows-x64.zip` below, check it against the `.sha256` file, unzip it.
2. Run `netshutup-modern.exe`, choose **Self-test (for testers)**, confirm, accept the administrator prompt.
3. Attach the two report files to a [test report](https://github.com/imardagokce/NetShutUp/issues/new?template=test-report.yml).

Step-by-step guide (English): [docs/TESTING.md](https://github.com/imardagokce/NetShutUp/blob/main/docs/TESTING.md) · Türkçe: [docs/TESTING.tr.md](https://github.com/imardagokce/NetShutUp/blob/main/docs/TESTING.tr.md).

### Good to know

- The `.exe` is **not code-signed**, so Windows SmartScreen may warn ("Windows protected your PC"). Check the checksum, then choose *More info → Run anyway* only if it matches. You can also build it yourself from source.
- Nothing is sent over the network; the report only exists on your computer.
- If something goes wrong: choose **Revert last change** (or run `netshutup-modern revert`), or use the System Restore point / `.reg` files the self-test made.
- Windows 7/8/8.1 are not supported by this line (see the `legacy` branch). On Windows 10 everything works except encrypted DNS, which is skipped.

### Known limits

- Real-machine testing is exactly what this release is for; expect rough edges.
- DNS-over-TLS is experimental (Windows documents no API for it).
- No installer, no GUI, no prebuilt signed binary yet.
