# DNS Provider + DoH (Alpha Stage 5a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each profile points the network adapters' DNS at a provider with encrypted DNS (DoH) required, proves it works with a real lookup, tries the next provider if not, and puts the old DNS back if nothing works.

**Architecture:** DNS becomes one new per-adapter catalog setting (`dns.resolver`, a list of servers with optional DoH settings) read and written through Windows' `Get/SetInterfaceDnsSettings`, so the existing backup/apply/revert engine covers it. A new `dns` module runs the trial chain after the engine has applied the profile, using a `Resolver` trait and the `Store` trait so the logic is tested with fakes. `commands.rs` wires it in and prints the messages.

**Tech Stack:** Rust 2024, `windows` 0.61.3 (add feature `Win32_NetworkManagement_Dns`), existing `serde`.

**Spec:** `docs/design/2026-11-17-dns-doh-5a.md` (parent: `docs/design/2026-11-16-alpha-release.md`).

## Global Constraints

- IPv4 DNS servers only; IPv6 DNS is not touched. DoT is out of scope (stage 5b).
- Provider table (verbatim): cloudflare `1.1.1.1`,`1.0.0.1` `https://cloudflare-dns.com/dns-query`; google `8.8.8.8`,`8.8.4.4` `https://dns.google/dns-query`; quad9 `9.9.9.9`,`149.112.112.112` `https://dns.quad9.net/dns-query`. Names shown to users: `Cloudflare`, `Google`, `Quad9`.
- DoH flags written: `2` (`DNS_DOH_SERVER_SETTINGS_ENABLE`) only: no UDP fallback (4), no auto-upgrade (1).
- Windows build < 22000: DNS stage skipped, no plain provider is set.
- Lookup names: `www.microsoft.com`, `example.com` (trial, tried in this order, first success wins); `fastest` measures with `www.microsoft.com`, `example.com`, `www.wikipedia.org`, `www.apple.com`, `www.cloudflare.com`: 1 warm-up + 5 timed lookups per provider, median compared. Each lookup gives up after 8 seconds. Cache and hosts file are bypassed.
- Profile assignments: privacy `["quad9","cloudflare"]` first_working; recommended `["cloudflare","google"]` first_working; performance `["cloudflare","google"]` fastest.
- Report URL (verbatim): `https://github.com/imardagokce/NetShutUp/security/advisories/new`
- Program text is English. No test touches the real network settings or DNS; tests that read the real system are read-only.
- Nothing is written before the backup is on disk (existing engine rule). A "not set" (DHCP) DNS must come back as not set.
- Commits: conventional prefixes, no Co-authored-by line. Run commands from `modern/`; full suite `cargo test`.

## Review Focus

1. Original DNS is DHCP (not set) and every provider fails: restored as `NotSet`, not an empty static list. → Task 4 `all_fail_restores_originals_exactly`.
2. No internet at the start: DNS targets are dropped, nothing is written for them, the user is told. → Task 4 `precheck_*`, Task 6 `dns_targets_are_dropped_unless_precheck_says_go`.
3. A provider is blocked and every lookup times out: chain still ends (bounded by 8 s per lookup). → Task 5 `with_deadline_gives_up_on_a_slow_call`.
4. Writing the second adapter fails after the first succeeded: both go back to the original. → Task 4 `write_failure_restores_originals_and_is_program_error`.
5. Windows normalises what was written so the read-back differs: treated as a program error, not as success. → Task 4 `readback_mismatch_is_a_program_error`.
6. The network blocks DoH: informative message, **no** report request. → Task 4 `messages_only_ask_for_a_report_on_program_errors`.

### Task 4: The trial chain (pure logic)

**Files:**
- Create: `modern/src/dns/mod.rs`
- Modify: `modern/src/main.rs` (`mod dns;`), `modern/src/settings/store.rs` (move `FakeStore` from `apply.rs` tests into `pub mod testing` under `#[cfg(test)]`, same behaviour, keep apply tests green)

**Interfaces:**
- Consumes: `Store`, `State`, `Provider`, `DnsSpec`, `Choose` (Tasks 1–3).
- Produces:

```rust
pub trait Resolver {
    /// Resolves `name` bypassing cache and hosts file; the time it took.
    fn lookup(&self, name: &str) -> Result<Duration, String>;
    fn flush_cache(&self);
}
pub enum Precheck { Go, NoInternet, Unsupported }
pub fn precheck(resolver: &dyn Resolver, windows_build: u32) -> Precheck;   // build < 22000 → Unsupported (no lookups); both TEST names fail → NoInternet

#[derive(Debug, PartialEq, Eq)]
pub enum Outcome {
    Encrypted { provider: String, skipped: Vec<String> },   // display names
    FellBack { tried: Vec<String> },
    ProgramError(String),
}
/// The engine has already written the first provider to `adapters`.
/// `originals`: (adapter guid, state before the change) for every adapter.
pub fn run(store: &dyn Store, resolver: &dyn Resolver, spec: &DnsSpec, adapters: &[String],
           originals: &[(String, State)], say: &mut dyn FnMut(&str)) -> Outcome;
pub fn message(outcome: &Outcome) -> String;
pub const REPORT_URL: &str = "https://github.com/imardagokce/NetShutUp/security/advisories/new";
```

Behaviour of `run` (spec "Akış" 3–4): for provider *i* (writing providers after the first to every adapter, then reading each back and comparing with `Provider::state()`), flush the cache, `say("Trying <Name> (encrypted DNS)...")`, trial = first TEST name that resolves. `FirstWorking` stops at the first success. `Fastest` measures every working provider (1 warm-up + 5 timed, median), then keeps the lowest median, rewriting it if it was not the last written. If nothing worked: write each original back (verify equal), flush, return `FellBack`. Any write/read-back/restore failure: restore originals, return `ProgramError(reason)` (if the restore itself fails the reason says which adapters could not be put back).
