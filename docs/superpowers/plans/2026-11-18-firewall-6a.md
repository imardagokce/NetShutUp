# Firewall base tier (6a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Every profile makes sure Windows Firewall is on and blocks inbound by default for Domain, Private and Public, skipping when a third-party firewall is registered.

**Spec:** `docs/design/2026-11-18-firewall-6a.md` (read it first).

## Global Constraints

- Rust 2024, `windows` 0.62.2 (add `Win32_NetworkManagement_WindowsFirewall` feature). Run from `modern/`; `cargo test` and `cargo build --release` stay green with **no warnings**.
- Never run `apply`, `revert`, `selftest`, never change firewall state; real COM writes are only compiled. The only executed real test is read-only.
- Tests first (see them fail). Files are CRLF: use the Edit tool or Python with `newline=""` handling. One commit per task, conventional prefix, **no Co-authored-by line**, do not push.
- Never parse `netsh` text. Program text is English.
- Setting ids (never change): `firewall.domain.enabled`, `firewall.domain.inbound`, `firewall.private.enabled`, `firewall.private.inbound`, `firewall.public.enabled`, `firewall.public.inbound`; scope `System`; `enabled` labels `[(0,"off"),(1,"on")]` default `Dword(1)`; `inbound` labels `[(0,"block"),(1,"allow")]` default `Dword(0)`. Names: `Firewall (Domain network)`, `Inbound connections (Domain network)` etc.

## Task 1: Firewall settings through COM

**Files:** Create `modern/src/settings/firewall.rs`; modify `settings/mod.rs`, `settings/catalog.rs`, `settings/store.rs`, `settings/profile.rs`, `modern/profiles/{privacy,performance,recommended}.json`, `modern/Cargo.toml`.

**Interfaces — Produces:**
- `catalog::Source::Firewall { network: Network, field: Field }` where `Network { Domain, Private, Public }` and `Field { Enabled, Inbound }` (define in `firewall.rs`, `Copy`, `Debug`, `PartialEq`); `is_writable()` true.
- `firewall::read(network, field) -> Result<u32, String>` and `firewall::write(network, field, value: u32) -> Result<(), String>` using `INetFwPolicy2` (`CoCreateInstance(&NetFwPolicy2)`, `FirewallEnabled`/`SetFirewallEnabled` with `NET_FW_PROFILE2_DOMAIN`=1, `PRIVATE`=2, `PUBLIC`=4; `DefaultInboundAction`/`SetDefaultInboundAction` with `NET_FW_ACTION_BLOCK`=0 and `ALLOW`=1; initialize COM like `wmi.rs` does; errors as `"firewall error <hex>"`, access denied wording as in `registry_error`).
- Store: `read` → `State::Value(Value::Dword(n))` or `State::Unavailable(reason)`; `write` accepts only `Value::Dword(0|1)`, otherwise `"value type does not match the setting"`.
- Profiles: `Desired::Dword` fits `Source::Firewall`. All three profile JSON files get all six assignments (`enabled` 1, `inbound` 0).

## Task 2: Third-party firewall skip, self-test hook, docs

**Files:** `settings/plan.rs`, `commands.rs`, `selftest/runner.rs`, `selftest/system_env.rs`, `selftest/diagnostics.rs` (reuse the SecurityCenter query), `modern/README.md`, root `README.md`, `docs/design/2026-11-16-alpha-release.md` (stage 6 line), `docs/design/2026-11-18-firewall-6a.md` (status).

**Interfaces — Produces:**
- `plan::third_party_firewall(products: &[String]) -> Option<String>`: first product whose name does not start with `Windows` (case-insensitive); empty/unknown list → `None`.
- `plan::drop_firewall(plan: Vec<PlannedChange>) -> Vec<PlannedChange>` (removes changes whose setting id starts with `firewall.`); `plan::is_firewall(&PlannedChange) -> bool`.
- `plan::plan_profile(...)` gains a parameter `third_party_firewall: Option<&str>`; when `Some`, firewall changes are dropped (rest unchanged). Real products come from `wmi::query_strings(r"ROOT\SecurityCenter2", "FirewallProduct", "displayName")` (errors → empty list).
- `commands`: the planning wrapper looks the products up and prints (stderr, once) `Another firewall (<name>) is registered, so Windows Firewall settings were left alone.`; the same text appears in the preview.
- `selftest::runner::Env` gains `fn third_party_firewall(&self) -> Option<String>` (real: via the helpers above; fake: a field); the runner passes it to `plan_profile`; when `Some` it adds an Info check `firewall.third_party` to the environment checks.
